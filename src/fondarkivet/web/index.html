Fondarkivet

A public archive of net asset values (NAVs) from Spiltan Fonder, AMF Fonder, and Handelsbanken Fonder. The archive refreshes nightly and records quotes by valuation date.

API

Download the data without an API key.

Fund catalog (JSON)
Fund names, share-class ISINs, currencies, and latest quote dates.
Latest NAVs (CSV)
One row per archived share class.
NAV history (CSV)
Find a share class in the catalog and use its ISIN in /v1/nav/{isin}.csv.
